# Pecta Mode

Расширение для Chrome и Firefox: инспектор выбранного слоя прямо в открытом редакторе Figma. Текущая сборка — **0.3.20**. Плагин Figma, отдельный сервер и токен API для включения панели не нужны.

Готовые сборки: [GitHub Releases](https://github.com/bogdanhpk/Pecta/releases/latest).

## Включение

1. Обновите уже установленное расширение на `chrome://extensions` и перезагрузите вкладку Figma. При первой установке включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку **`chrome`** из распакованного архива. Для сборки из исходников используйте **`dist/chrome`**.
2. Откройте макет на `figma.com/design/…` или `figma.com/file/…`, дождитесь загрузки и нажмите значок **Pecta Mode** на панели расширений.
3. Справа появится панель Pecta. Выберите слой в макете или в дереве Figma. Панель продолжает работать после закрытия окна расширения.
4. Повторное нажатие значка или крестик в панели выключает Pecta Mode.

Для автоматической проверки доступности нужен доступ Pecta к `figma.com`. После обновления разрешите его в настройках расширения и перезагрузите вкладку Figma.

Если после обновления видите прежнее окно диагностики, проверьте, что Chrome загружает папку `dist/chrome` именно этого проекта. Версия указана в меню `…` панели и на странице диагностики.

В Firefox откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение» и выберите **`firefox/manifest.json`** из архива или **`dist/firefox/manifest.json`** после сборки из исходников. Для обновления нажмите «Перезагрузить» у дополнения, затем перезагрузите вкладку Figma. Временная установка действует до перезапуска Firefox. Минимум — Firefox 128.

## Обновления через GitHub

В меню `…` панели выберите «Check for Updates». При доступном обновлении на кнопке меню появляется красная точка. Открытие меню убирает её для этой версии; точка у «Check for Updates» остаётся до установки обновления. Просмотренная версия сохраняется локально, при следующей новой версии точка на кнопке появляется снова. Страница обновлений показывает установленную и последнюю версии, ссылку на ZIP для вашего браузера, блок «What’s new» с описанием из GitHub Release и порядок установки. Описание показывается для новой версии; если автор его не добавил, Pecta сообщает об этом. Списки, заголовки, ссылки и код отображаются без выполнения HTML. Длинное описание сокращается со ссылкой на полный релиз.

При открытии панели Pecta проверяет последний стабильный релиз в `bogdanhpk/Pecta`; успешный результат кэшируется на шесть часов. Пока панель открыта, проверка повторяется раз в шесть часов. Изменения результатов проверки и просмотренной версии синхронизируются между открытыми панелями. Ручная проверка обновляет его, но запросы выполняются не чаще раза в минуту. Черновики, prerelease, старые версии и сборки с неподходящими именами или адресами не предлагаются. Ошибка сети не выдаётся за отсутствие обновлений.

Скачайте архив, замените содержимое прежней папки установленного расширения, нажмите «Перезагрузить» на странице расширений и перезагрузите Figma. Сохранение прежнего пути к папке Chrome сохраняет идентификатор распакованного расширения и его настройки. До версии 0.3.15 нет проверки GitHub: эту сборку нужно поставить вручную один раз.

Текущие ZIP-сборки не устанавливаются автоматически. Для штатных автообновлений Chrome на macOS/Windows нужна публикация в Chrome Web Store или корпоративная установка; Firefox требует подписанный XPI и настроенный канал обновлений. Кнопка Pecta скачивает сборку, а не заменяет расширение скрыто. [Chrome distribution](https://developer.chrome.com/docs/extensions/how-to/distribute), [Firefox self-distribution](https://extensionworkshop.com/documentation/publish/self-distribution/).

## Что работает

- Размеры и положение слоя, отступы и расстояния до родителя и соседних слоёв.
- Auto layout, заливки, обводки, эффекты и радиусы.
- CSS с подсветкой и копированием. Переключение px/rem.
- Типографика, текстовые стили и токены с исходными названиями.
- Цвета выделения в Hex, RGB и HSL.
- Свойства и превью компонентов, просмотр вариантов.
- Превью ресурсов и скачивание PNG; для иконок — SVG.
- Обновление свойств при выборе и изменении слоя.
- Светлая и тёмная темы, изменение ширины панели.

## Доступ и ограничения

Доступ к модели `figma` в основном контексте страницы подтверждён диагностическими отчётами на реальном файле. Панель использует этот же способ чтения, не включает встроенный платный Dev Mode и не меняет права пользователя. Совместимость такого доступа после обновлений Figma не гарантирована. Работа панели в настоящем Figma с правами только просмотра требует отдельной проверки; автоматические браузерные проверки используют контрольную модель.

Пока это реализованное ядро инспектора, а не полное покрытие функций Dev Mode. Нет измерения расстояний до соседнего элемента по Alt и раздельной типографики для диапазонов внутри одного текстового слоя. Смешанные значения отмечаются как «Mixed», а недоступный CSS — как недоступный, без приблизительной генерации.

Рендерится только один выбранный слой; всё дерево большого файла не обходится. В активной вкладке изменения проверяются каждые 250 мс, в фоновой — каждые 1200 мс. Имена переменных кэшируются на пять секунд (до 256 записей). Библиотечные данные обновляются также раз в пять секунд, чтобы замечать переименования. Превью читается отдельно от CSS и метаданных, только для одного выбранного компонента при открытой секции. Размер PNG ограничен 512 px по длинной стороне и 512 КБ; в памяти кэшируется до восьми превью на пять секунд. Одновременно выполняется один экспорт. Превью не отправляются на сервер и не записываются в хранилище. Список вариантов ограничен первыми 128 элементами и текущим главным компонентом; сокращение списка отмечается. Всё дерево документа не обходится.

Чтения CSS, компонента и переменных идут параллельно, с таймаутом четыре секунды. Для текста также читаются связанные текстовый и цветовой стили и до 16 коллекций переменных; метаданные кэшируются на пять секунд. Общий срок чтения этих сведений — четыре секунды, после чего показываются доступные результаты. Токен текстового стиля используется у свойства, только если оно не переопределено в выбранном слое. Одновременно обрабатывается один полный снимок, промежуточные запросы объединяются; ответы от старого выделения отбрасываются.

Пределы чтения: до 256 прямых соседей для измерения расстояний, до 32 привязок переменных, 20 заливок/обводок, 60 полей CSS, 16 КБ на значение CSS, 32 768 символов текста. Сокращение CSS и текста отмечается, их копирование при этом блокируется. У больших родителей показываются измеренные расстояния до границ родителя; повёрнутые выделения не получают прямоугольные внешние измерения. Это ограничения текущего инспектора, а не ограничения Figma.

Selection colors сначала читает штатный список цветов Figma; если он недоступен, цвета собираются из выбранного поддерева. Поиск Assets ограничен 2000 слоями, 32 ресурсами и 1,5 секунды обхода; список цветов — 64 записями. Обход отдаёт управление между порциями работы, скрытые ветки пропускаются. Имена разрешаются отдельно с ожиданием до двух секунд и кэшем пять секунд. Сокращение списка и недоступные свойства отмечаются в панели. Данные обновляются при смене выделения и раз в пять секунд. Превью Assets ограничено 256 px и 512 КБ; скачивание — 8192 px по длинной стороне, 8 МБ для PNG и 2 МБ для SVG. Превью и скачивания используют общий с компонентами слот экспорта: одновременно выполняется один экспорт. Ошибки и ограничения доступа Figma показываются в строке ресурса.

Данные слоя не отправляются на сервер и не сохраняются в хранилище расширения. Локально сохраняются ширина панели, выбранная единица измерения, вид List/Code, формат цвета, последняя просмотренная версия обновления и ID последней вкладки для открытия диагностики. Разрешения: `activeTab` и `scripting` для подключения по нажатию, `storage` для настроек, `clipboardWrite` для копирования по действию пользователя. Автоматическая проверка использует разрешения на `https://figma.com/*` и `https://www.figma.com/*`. Проверка обновлений использует дополнительное разрешение только на `https://api.github.com/*`; запрос содержит адрес последнего релиза Pecta, без данных макета и авторизации. Локально сохраняются версия, описание изменений, ссылки на сборки и время проверки. Доступа ко всем сайтам нет. Проверка иконки читает только доступность выделения, не копирует свойства слоёв и не меняет документ. Повторная проверка идёт раз в две секунды в видимой вкладке Figma, а также при загрузке, активации вкладки и фокусе окна. При отсутствии доступа иконка остаётся серой.

## Диагностика

Диагностика доступа открывается через настройки расширения в браузере.

«Inspect layer» сохраняет один снимок. «Observe for 20 s» проверяет изменения через события и опрос, сохраняет до восьми полных снимков и до 16 записей изменений. После переключения слоёв вернитесь на страницу и нажмите «Refresh». «Download JSON» выгружает локальный отчёт, содержащий имена и свойства проверенных слоёв. Старые результаты помечаются версией сборки и не выдаются за новую проверку.

## Сборка и проверки

Нужен Node.js 20+. Зависимостей для работы и сборки расширения нет.

```sh
npm run build
npm test
```

Исходники находятся в `src`, сборки — в `dist/chrome` и `dist/firefox`. Функция чтения встраивается в MAIN-скрипт при сборке; UI выполняется отдельно в изолированном контексте с Shadow DOM. Иконки Phosphor, включая синий и серый значки панели браузера, распространяются по MIT, лицензия включена в `src/assets`. Inter 4.1 включён в `src/assets/fonts` с лицензией SIL OFL 1.1.

Для браузерных проверок используются отдельные профили и контрольная HTML-модель на перехваченном адресе `www.figma.com`; настоящие аккаунты и файлы не открываются. Разрешения тестовой копии совпадают с обычной сборкой. Буфер обмена подменён в изолированном контексте, системный буфер не меняется.

```sh
# Необязательная зависимость только для Chrome QA
npm install --no-save playwright
npx playwright install chromium
npm run test:chrome

# Системный Firefox, без npm-зависимостей
npm run test:firefox
```

Можно указать `CHROME_PATH`, `PLAYWRIGHT_MODULE` или `FIREFOX_PATH`. Firefox QA требует актуальный браузер с WebDriver BiDi. Скриншоты и журналы сохраняются в `output/playwright/`.

Проверки Chrome включают переключение слоёв, гонку медленных ответов, CSS/токены/компоненты, копирование, светлую/тёмную темы, ресайз и сохранение ширины, пустое/множественное выделение, безопасный вывод текста, выключение и повторное включение. Отдельно проверяется совместимость с Trusted Types. Автотесты не заменяют проверку панели в настоящем Figma.

## Публикация новой сборки

GitHub Actions автоматически запускает тесты и сборку после изменений в `main`. Если версия из `package.json` ещё не опубликована, workflow `Build and release` создаёт GitHub Release с ZIP для Chrome и Firefox и `SHA256SUMS.txt`. Публикация происходит после загрузки обоих архивов; существующие публичные релизы не перезаписываются. Релизы также можно запускать тегом `vX.Y.Z` или вручную на вкладке Actions. Версия тега должна совпадать с `package.json`.

Для следующей сборки повысьте `version` в `package.json`, добавьте описание под заголовком `## X.Y.Z` в `CHANGELOG.md` и отправьте изменения в `main`. Workflow переносит описание этой версии в GitHub Release; без него публикация не выполняется. Отдельный токен не нужен: workflow использует `GITHUB_TOKEN` этого репозитория. Проверки pull request не публикуют релиз.

Локальная упаковка требует системную утилиту `zip`:

```sh
npm test
npm run package
```

Архивы и контрольные суммы появляются в `releases/`; исходники, шрифт и лицензии хранятся в репозитории, сгенерированные ZIP и `dist/` в Git не добавляются.
